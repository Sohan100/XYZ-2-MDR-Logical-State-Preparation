- Error models. For a pilot ratio R, z = |ln R|/sigma, with the same model whether XYZ^2 leads or trails:
  (a) Poisson: sigma^2 = 1/N1 + 1/N2 over the two error counts.
  (b) Uniform shot-level scaling: sigma^2 = f1^2/N1 + f2^2/N2. A pool takes f = max(1, sqrt(chi2/dof)) from its own replicates, and a single run takes f = 1.7 (m1's 1.66). Where f > 1 is estimated from k replicates, z is read as Student t on k - 1 dof and converted to a Gaussian-equivalent sigma.
  (c) Run-level offset: each XYZ^2 BM run gets an extra log-rate variance delta^2, and runs are pooled by inverse variance. A set of runs then has E[chi2] - dof = delta^2 W, with W = sum_i mu_i(1 - mu_i/E), where mu_i is the expected error count of run i and E the set's total.
